About this version

This starter web version uses the TensorFlow.js COCO-SSD model. It recognizes 80 common object classes such as people, cars, trucks, dogs, cats, chairs, TVs, laptops, bottles and many food items. Highly specific objects, exact car models, individual people, receipts, or custom inventory categories would need a more advanced model.

Browser limitation: a web page cannot silently move or rename files on your computer. Instead, this app builds a new categorized ZIP while leaving the originals untouched.
