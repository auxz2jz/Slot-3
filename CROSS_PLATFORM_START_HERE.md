# Inventory Box — Cross-Platform Start Here

Inventory Box is now one product with separate Android and Windows implementations.

Before working on the project:

1. Read `auxz2jz/master-instruction-library/INSTRUCTION_INDEX.md`.
2. Read `CROSS_PLATFORM_COLLABORATION_STANDARD.md`.
3. Read `shared/PROJECT_VISION.md`, `shared/FEATURE_CATALOG.md`, `shared/SHARED_REQUIREMENTS.md`, `shared/SHARED_DECISIONS.md`, `shared/DATA_FORMATS_AND_INTERFACES.md`, and `shared/OWNERSHIP_BOUNDARIES.md`.
4. Determine whether you own Android or Windows for the current task.
5. Read only that platform's status/memory/roadmap/checkpoint files before changing source.

The root web files predate the current native cross-platform structure and are preserved as legacy material. They are not the current Android baseline and should not be used as Windows implementation source.

Current platform ownership:

- Android: Android chat/workflow
- Windows: PC/Codex agent

Current Android last verified baseline: **v0.29.0 / build 33**.

Current Windows last verified baseline: **NONE / NOT STARTED** in this repository record.
